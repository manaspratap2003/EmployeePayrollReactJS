# EmployeePayrollReactJS

A React JS based Employee Payroll Application built during BridgeLabz Full Stack Training.

## Tech Stack
- React JS (Create React App)
- HTML5 / CSS3 / JavaScript ES6+
- Local Storage API
- Async, Ajax, Callback and Promise
- JSON Server (Mock REST API)

## Use Cases
- UC1 : React Basic Setup
- UC2 : Employee Model and Form Component
- UC3 : Local Storage Service
- UC4 : Display Payroll Home Page
- UC5 : Full CRUD Operations
- UC6 : Async Ajax Service Layer
- UC7 : JSON Server HTTP Service

## Branch Strategy
- main     : Stable production code
- develop  : Integration branch
- feature/ : Feature branches merged into develop
